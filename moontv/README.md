# 影视资源订阅

#### 支持 MoonTV / LunaTV / Helios 以及其他衍生项目

## 通用订阅（推荐使用）

URL：[https://quan-ge.github.io/quan-ge/moontv/moontv_sub.txt](https://quan-ge.github.io/quan-ge/moontv/moontv_sub.txt)

过滤成人内容、国内不可用、速度慢的源

## R18版本

URL：[https://quan-ge.github.io/quan-ge/moontv/moontv_sub_r18.txt](https://quan-ge.github.io/quan-ge/moontv/moontv_sub_r18.txt)

不过滤成人内容

## ALL版本

URL：[https://quan-ge.github.io/quan-ge/moontv/moontv_sub_all.txt](https://quan-ge.github.io/quan-ge/moontv/moontv_sub_all.txt)

完整版，不过滤任何内容，**使用时会因为源过得导致速度变慢，部分部署方式会导致应用部署失败**


# 不支持订阅时的使用订阅方法（旧版或其他衍生项目）

 - 访问订阅的URL，将订阅复制下来

 - 前往[https://www.udtool.com/toolbox/base58-encoder-decoder.html?charsetInput=12](https://www.udtool.com/toolbox/base58-encoder-decoder.html?charsetInput=12)

 - 将订阅转为配置文件

 - 手动导入配置文件
